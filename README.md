**CPU 和存储：同价位优先新平台**

第三方整理的说法是，AMD EPYC 7002 系列相比 Intel E5v4 整体性能强 50%–100%。同样月付 19 元的价位，新平台和老平台能差出一代的性能。存储上 NVMe 比 SATA SSD 的 4K 随机读写高一个量级，做数据库、跑 Docker 的差别比跑静态页明显。

**线路：150ms 和 300ms 的差别**

美国 VPS 的线路大致三档。普通国际 BGP 最便宜，国内方向绕路，晚高峰丢包；优质 BGP 三网直连（电信 163 + 联通 4837 + 移动 CMI）国内 ping 约 150–180ms；CN2 GIA / CTGNet 这类精品线路贵，主要优势是晚高峰不容易掉速。第三方资料里，CN2 GIA 和优质 BGP 的延迟区间其实重叠，都在 150–180ms，真正的差异在高峰期稳定性，不在 ping 值本身。

市面上标了 CN2 GIA 的在售套餐有 63 款，联通 9929 的 48 款，移动 CMIN2 的 33 款，三网优化 11 款。精品线路是少数派，价格自然下不来。

DMIT 洛杉矶分三条线：Pro 走 CN2 GIA + AS9929 + CMI/CMIN2，EB 回程走 CMIN2，T1 是国际线路。同样是 1核2GB/20GB 这一档，T1 TINY 是 $6.90/月，Pro TINY 是 $37.99/季起（约 $12.66/月），贵了约 80%。T1 晚高峰延迟飙到 300ms 以上是常态，Pro 能稳在 160ms 上下。这 80% 就是线路的价格。

## 流量计费还是带宽计费，同价位能差几十倍

同一个月付价，商家可能给两种完全不同的产品。野草云 1核1GB 这一档，流量计费款是 500Mbps 端口 + 1TB 月流量，¥19/月；带宽计费款是 5Mbps 端口 + 不限流量，同样 ¥19/月。价格一样，用途完全不同。

流量计费适合建站、API 这类带宽波动大但月总量不高的场景，跑满流量后会被限速。野草云的规则是超流量限速到 1Mbps，次月 1 日重置，流量双向统计，买个流量重置附加服务能提前恢复。DMIT 的做法是不停机，直接限速继续跑。

带宽计费适合 24 小时持续占带宽的场景，比如视频推流、大文件分发。代价是小端口。

AkkoCloud 站内把这两种模式的价差摆得很清楚：A2 mini 年付折 ¥37.42/月，给 1Gbps 端口和 800GB 月流量；U1 要 ¥1200/月，给 30Mbps 端口和不限流量。同一家、同一机房，价差 32 倍，买的不是 CPU 和内存，是"不限流量"这四个字。流量用不到 800GB 的人买 U1，钱基本是白花的。
